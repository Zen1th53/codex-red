## LinkedIn

I have released **codex-red**, an open-source collection of 79 offensive-security skills adapted for the OpenAI Codex skill system.

The library covers 23 categories, including web and API testing, Active Directory, cloud, containers, exploit development, fuzzing, OSINT, wireless, mobile, TLS, privilege escalation, and professional reporting.

For the Codex adaptation:

- 28 legacy skill documents were converted to valid Codex `SKILL.md` frontmatter;
- all 79 skills passed the Codex skill validator;
- installation was adapted to place every skill directly in `~/.codex/skills`;
- the installer was tested end-to-end with all 79 packages;
- upstream MIT attribution was preserved.

Repository: https://github.com/Zen1th53/codex-red

### Body

I adapted an MIT-licensed offensive-security skill collection for OpenAI Codex.

The repository contains 79 focused `SKILL.md` packages across 23 categories: web, APIs, authentication, Active Directory, cloud, containers, CI/CD, cryptography, exploit development, fuzzing, OSINT, wireless, mobile, IoT, networking, privilege escalation, post-exploitation, and reporting.

All 79 skills pass the Codex validator, and the installer was tested against a clean temporary skills directory.
